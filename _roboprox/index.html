Roboprox Note Generator

This structure is in YAML format. You only need to fill in the values on rows **without** # - those are comments
Each record is preceded with key:, such as PUBLISHER:. Your data follows in a presented form.
Each colon : needs to be followed by space
Text values need to be put between quotation marks; see TYP_LICENCE
Records within {} and [] brackets need to be separated with comma and space; see GROUP
Check the correctness of the format here https://jsonformatter.org/yaml-validator
